# MVP Scope

## 제품 정의

Schedule Butler MVP는 사용자가 붙여넣은 정제되지 않은 텍스트에서 일정 후보를 추론하고, 승인받은 내용만 가상 캘린더에 등록하는 모바일 웹앱입니다.

## 입력

1차 MVP 입력:

- 카톡 대화 원문
- 이메일 원문
- 통화 STT 텍스트
- 일반 메모

1차 MVP 제외:

- 이미지 OCR
- 음성 파일 직접 STT
- 계정 연동을 통한 자동 수집

## 일정 상태

### `confirmed_event`

날짜, 시간, 제목 또는 맥락이 충분한 일정입니다.

예:

```text
내일 오후 3시에 강남역에서 팀 회의하자.
```

앱 동작:

- AI가 일정 초안을 만듭니다.
- 사용자에게 "이렇게 등록할까요?"라고 묻습니다.
- 승인 후 `Event`, `ChecklistItem`, `Notification`을 생성합니다.

### `negotiating_event`

회의 가능한 시간이 오가지만 아직 확정되지 않은 상태입니다.

예:

```text
A: 토요일 4시 이후 가능
B: 일요일 하루종일 가능
C: 토요일 7시는 안돼요
나: 일요일은 시간이 미정이라 토요일 먼저 정하면 될 것 같습니다
```

앱 동작:

- 참석자별 가능/불가능 시간을 추출합니다.
- 공통 후보 시간을 계산합니다.
- 후보가 명확하면 "이 시간은 어떤가요?"라고 제안합니다.
- 충돌이 있으면 "이렇게 다시 물어볼까요?"라고 메시지 초안을 제안합니다.
- 승인 전에는 `Event`를 만들지 않습니다.

### `needs_more_info`

날짜, 시간, 참석자, 장소 중 핵심 정보가 부족한 상태입니다.

앱 동작:

- 부족한 정보를 설명합니다.
- 사용자나 상대에게 보낼 질문 초안을 만듭니다.

## 화면

필수 화면:

- 원문 입력 화면
- AI 분석/승인 대화 화면
- 오늘 일정 화면
- 이번 주 캘린더 화면
- TODO 리스트 화면
- 일정 상세 및 체크리스트 화면

## 알림

1차 MVP:

- 앱 내부 알림 목록
- 브라우저 Notification API 기반 알림
- 일정 30분 전 알림
- 장소 또는 준비물이 있는 일정의 출발 전 체크리스트
- 회의/야외 활동/운동/여행 등 문맥 기반 체크리스트 추천
- 앱이 열려 있을 때 예약 알림 자동 표시 및 확인/취소 상태 관리

제외:

- 실제 iOS push notification
- 백그라운드 위치 기반 출발 시간 계산

## 저장 데이터

필수 엔티티:

- `RawInput`
- `ExtractionDraft`
- `Event`
- `Todo`
- `ChecklistItem`
- `Notification`

## 완료 기준

- 샘플 카톡 대화를 붙여넣으면 시간 조율 중인 일정으로 분류된다.
- 참석자별 제약이 화면에 보인다.
- 공통 후보 또는 추가 질문 초안이 생성된다.
- 승인하면 일정/TODO/체크리스트가 DB에 저장된다.
- 오늘/이번 주 화면에서 저장된 일정이 보인다.
