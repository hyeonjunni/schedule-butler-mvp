# 3-Day Implementation Plan

## Day 1: 입력과 AI 승인 플로우

목표:

- 모바일 웹앱 골격을 만든다.
- 원문 텍스트를 붙여넣고 AI 분석 결과를 승인 대화로 보여준다.

작업:

- Next.js 프로젝트 생성
- iPhone 스타일 레이아웃 구현
- 원문 입력 화면 구현
- `/api/extract` route 구현
- AI JSON schema 검증
- 승인/수정/취소 UI 구현

검증:

- 샘플 카톡 원문 입력 시 `negotiating_event`로 분류된다.
- 확정 일정 샘플 입력 시 승인 메시지가 나온다.
- AI 응답이 깨져도 사용자가 볼 수 있는 오류 상태가 나온다.

## Day 2: DB 저장과 캘린더/TODO

목표:

- 승인된 결과만 DB에 저장한다.
- 저장된 일정과 TODO를 볼 수 있다.

작업:

- Prisma 설정
- PostgreSQL 연결
- `RawInput`, `ExtractionDraft`, `Event`, `Todo`, `ChecklistItem`, `Notification` 모델 작성
- 승인 API 구현
- 오늘 일정 화면 구현
- 이번 주 일정 화면 구현
- TODO 리스트 화면 구현

검증:

- `.env`의 DB 연결 정보로 migration이 실행된다.
- 승인 전에는 `Event`가 생성되지 않는다.
- 승인 후 오늘/이번 주 화면에 일정이 보인다.

## Day 3: 시간 조율과 알림

목표:

- 회의 조율 대화에서 공통 후보와 충돌을 제안한다.
- 일정 전 알림과 체크리스트를 생성한다.

작업:

- 참석자별 가능/불가능 시간 UI 구현
- 공통 가능 시간 계산 함수 구현
- 후보 시간 제안 및 추가 질문 초안 구현
- 알림 생성 로직 구현
- 브라우저 Notification API 연결
- 샘플 원문 테스트 정리

검증:

- 시간 조율 샘플에서 바로 일정 등록하지 않는다.
- 후보 시간이 있으면 제안 메시지를 보여준다.
- 충돌이 있으면 추가 확인 메시지를 제안한다.
- 일정 30분 전 알림 데이터가 생성된다.
